#Python File Organizer

This repository contains python automation projects about file organizing.
1. We start with the basic logic of file organizing such as finding out file types, creating respective directories
   and moving them. **Location:** `basic.py`
2. Proceed to use better python modules like Path to extract and configure paths, improving approach.
    **Location:** `organize.py`
3. Finally we implement changes to let the script run on its own whenver a download happens on the device
   (with the help of Watchdog Module) and then letting the script auto organize.
    **Location:** `auto_organize.py`
